How business editing works

  1. Words — edit definitions, examples, synonyms (master word bank).
  2. Lists — rename lists, set GRE vs dictionary type.
  3. Dictionary — add/remove words in flat dictionary lists.
  4. Import CSV — bulk edit in Google Sheets, then upload here.
  5. Publish — saves JSON and syncs the student app (www/).

Google Sheets workflow

Export CSVs → edit in Sheets (one tab per file) → Import CSV tab → Publish.

Or edit directly in this CMS without Sheets.
